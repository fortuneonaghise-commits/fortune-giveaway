FORTUNE GIVEAWAY — WEBSITE STARTER

Files:
- index.html: homepage and application form
- style.css: mobile-friendly black-and-gold design
- script.js: demo form behavior

IMPORTANT:
This is a front-end starter. The form does NOT submit or store applications yet.
Do not publish it as a live application service until a secure backend/form endpoint,
administrator authentication, access policies, and Telegram notifications are configured.
Never place a Telegram bot token or other secret in HTML/JavaScript files.

To preview on Android:
1. Extract the ZIP.
2. Open index.html with a browser, or use a code editor that previews HTML.
3. For hosting, upload the site files to your chosen host.

Next build step:
Connect a secure form endpoint that stores submissions privately and sends Telegram
notifications from the server, with the bot token kept in environment variables.
